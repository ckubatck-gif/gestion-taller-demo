# Gestión de Taller — Demo de portfolio

Aplicación web demostrativa para la gestión operativa de un taller mecánico.

> **Aviso:** este proyecto es exclusivamente una demostración. Los nombres, vehículos, matrículas, importes y órdenes son ficticios. La aplicación guarda los datos en el almacenamiento local del navegador. No introduzcas información personal ni utilices los documentos generados como documentos comerciales reales.

## Funcionalidades demostradas

- Panel de actividad con órdenes abiertas, presupuestos pendientes e indicadores de gestión.
- Órdenes de reparación y ciclo de estados.
- Fichas de clientes y vehículos.
- Asignación de trabajadores y costes por hora.
- Registro de mano de obra y recambios.
- Elaboración de presupuestos y registro de su aceptación.
- Registro y autorización de averías adicionales.
- Resguardos, presupuestos y resúmenes imprimibles.
- Estimación de costes, beneficio directo y márgenes.
- Informes de rentabilidad por periodo.
- Copias de seguridad y restauración de datos locales.

## Límites conocidos

- No hay cuentas de usuario, backend ni sincronización entre dispositivos.
- La persistencia se realiza exclusivamente en `localStorage`.
- La aplicación no emite facturas fiscales ni sustituye al software de facturación del taller.
- Los documentos generados son demostrativos y no deben entregarse a clientes.
- Los datos se guardan en el dispositivo desde el que se utiliza la demo.

## Tecnologías

React 18, Tailwind CSS (CDN), Babel Standalone y LocalStorage.

## Contexto

Prototipo propio desarrollado como propuesta de solución para un negocio del sector de la automoción. No se presenta como implantación comercial ni como producto de un cliente.
